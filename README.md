# 이끔

운동 기록과 2D 운동 친구를 위한 개인 건강 앱 **이끔**의 설치 파일 배포 저장소입니다.

소스 코드는 비공개입니다. 이 저장소에는 설치 파일과 자동 업데이트 정보만 있습니다.

## 내려받기

[최신 릴리즈](https://github.com/riedle03/ikkeum/releases/latest)에서 운영체제에 맞는 파일을 받으세요.

- Windows: `Ikkeum-Setup-*.exe` (설치형, 자동 업데이트) 또는 `Ikkeum-Portable-*.exe` (휴대용)
- macOS Apple Silicon(M1 이후): `Ikkeum-*-mac-arm64.dmg`
- macOS Intel: `Ikkeum-*-mac-x64.dmg`
